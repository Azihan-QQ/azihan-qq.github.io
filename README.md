# azihan-qq.github.io

Website portofolio Azihan, dibuat dengan [Astro](https://astro.build) dan tayang di https://azihan-qq.github.io.

## Mengubah isi

Semua teks (bio, pengalaman, skill, proyek) ada di `src/data/profile.ts`. Edit file itu, commit ke `main`, dan website akan ter-update otomatis lewat GitHub Actions.

## Menjalankan di komputer sendiri

```sh
npm install
npm run dev
```

Lalu buka http://localhost:4321.
